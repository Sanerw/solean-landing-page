# Solean Landing Page

The landing page for Solean. Built with SvelteKit, Svelte 5, Tailwind CSS v4,
and shadcn-svelte.

## Requirements

- Node.js (see `engine-strict` in `.npmrc`)
- pnpm

## Getting started

```sh
pnpm install
pnpm dev
```

The dev server runs at http://localhost:5173.

## Commands

| Command            | What it does                                |
| ------------------ | ------------------------------------------- |
| `pnpm dev`         | Start the dev server                        |
| `pnpm build`       | Build for production                        |
| `pnpm preview`     | Preview the production build locally        |
| `pnpm check`       | Typecheck with `svelte-check`               |
| `pnpm check:watch` | Typecheck in watch mode                     |

## Deployment

The project uses `@sveltejs/adapter-auto`. Swap in a target-specific adapter once
the host is decided.
